# Spring Boot Interview Questions and Answers

## Spring Boot Basics

1. Why would you choose Spring Boot over the Spring Framework?
- Spring Boot simplifies Spring application development by reducing configuration and setup work.
- Spring Boot because it simplifies Spring application development. It provides auto-configuration, 
  starter dependencies and embedded servers, so we can focus more on business logic and less on configuration.
-------------------------------------------------------------------------------------------------------------------------------------

2. What Spring Boot starters have you used?
Common starters:
- spring-boot-starter-web - REST APIs and web applications
- spring-boot-starter-data-jpa - JPA/Hibernate database access
- spring-boot-starter-validation - Bean Validation
- spring-boot-starter-security - Spring Security
- spring-boot-starter-test - Testing
- spring-boot-starter-actuator - Monitoring and management
- Spring Kafka dependencies - Kafka integration

-------------------------------------------------------------------------------------------------------------------------------------
3. How do you run a Spring Boot application?

Using Maven:
mvn spring-boot:run

After packaging:
mvn clean package
java -jar target/application.jar

-------------------------------------------------------------------------------------------------------------------------------------
4. What is the purpose of @SpringBootApplication?

@SpringBootApplication is a convenience annotation that combines:
- @SpringBootConfiguration
- @EnableAutoConfiguration
- @ComponentScan

It is normally placed on the main Spring Boot application class.

-------------------------------------------------------------------------------------------------------------------------------------
5. Can we use @EnableAutoConfiguration, @ComponentScan and @Configuration instead of @SpringBootApplication?
Yes.
Conceptually, @SpringBootApplication provides these capabilities together. Using the individual annotations is possible, 
but @SpringBootApplication is the normal and simpler approach.

-------------------------------------------------------------------------------------------------------------------------------------
6. What is Auto-Configuration in Spring Boot?

Spring Boot Auto-Configuration automatically configures appropriate Spring beans based on the application's classpath, configuration and conditions.

It is conditional. Spring Boot does not simply configure everything; it checks conditions before applying an auto-configuration.

-------------------------------------------------------------------------------------------------------------------------------------
7. How can you disable a specific Auto-Configuration class?

Using exclude:

@SpringBootApplication(exclude = {DataSourceAutoConfiguration.class})

It can also be configured through:
spring.autoconfigure.exclude=org.springframework.boot.autoconfigure.jdbc.DataSourceAutoConfiguration,
                             org.springframework.boot.autoconfigure.security.servlet.SecurityAutoConfiguration

9. How do you customize the port in Spring Boot?

application.properties:
server.port=8081

application.yml:
server:
  port: 8081

Command line:

10. How does SpringApplication.run() work internally?

At a high level:
1. Creates/configures SpringApplication.
2. Prepares the environment.
3. Creates the ApplicationContext.
4. Loads configuration classes.
5. Performs component scanning.
6. Applies auto-configuration.
7. Creates and initializes beans.
8. Starts the embedded server for a web application.
9. Runs startup runners.
10. Publishes application lifecycle events.

-------------------------------------------------------------------------------------------------------------------------------------
11. What is CommandLineRunner in Spring Boot?

CommandLineRunner is a functional interface used to execute code after the Spring application context has been created and the application has started.

Example:

@Component
public class StartupRunner implements CommandLineRunner {
    @Override
    public void run(String... args) {
        System.out.println("Application started");
    }
}

What is spring boot auto configuration ? How it works behind the scene?
     - Spring boot auto configuration is the way where spring boot automtically configure your application where you dont have to do 
       everything manually
     - 1) First Application Starts up and then it scans this @SpringBootApplicatin annotation this tells spring to start looking for 
 	  configuration, component in your project
       2) Then it eables @EnableAutoConfiguration it start setting ub database, web server and everyting that your application needs
       3) Since auto configuration begins it needs a settings to configure database and all so it start looking and load   		  application.properties file
       4) Then it register all the beans that your appliction need. For example your services, controller
       5) Once everything is set your application is ready to handle request without you writing the configuration code.

                                                Application Start up
                                                          |
                                                        Scan
                                                 @SpringBootApplication
                                                          |
                                                 EnableAutoConfiguration
                                                          |
						 Load application.properties
                                                          |
                                                   Register Beans
	                                                  |

Short answer:
Spring Boot examines the application's classpath, configuration and conditional requirements and then applies suitable auto-configuration.

Simplified flow:

Application starts
       |
SpringApplication.run()
       |
Create ApplicationContext
       |
Read configuration/environment
       |
@EnableAutoConfiguration
       |
Discover auto-configuration candidates
       |
Evaluate conditions
       |
Register applicable beans/configuration
       |
Create and initialize beans
       |
Start embedded server
       |
Application ready

Important:
Auto-configuration does not simply read application.properties and register every required bean. It uses auto-configuration classes and 
conditional rules based on classpath dependencies, existing beans, properties and other conditions.

13. How do we resolve circular dependency in Spring Boot?

A circular dependency occurs when beans depend on each other directly or indirectly.

Example:
ServiceA -> ServiceB
ServiceB -> ServiceA

Preferred solution:
Redesign the classes to remove the circular dependency. Often common logic can be moved into a third service.

If a cycle is genuinely unavoidable, techniques such as @Lazy can sometimes defer bean creation, but this should 
generally be treated as a workaround rather than the preferred design.

## Annotation-Based Questions

1. What is @RestController?

@RestController is a convenience annotation that combines:
@Controller
@ResponseBody

It is commonly used for REST APIs. Return values from controller methods are written directly to the HTTP response body, usually as JSON.

2. What is @Service?

@Service is a stereotype annotation used to identify a Spring-managed component that normally contains business/service logic.

3. What is @Advice?

For Spring MVC global exception handling, the commonly used annotations are:
- @ControllerAdvice
- @RestControllerAdvice

There is not a standard Spring MVC annotation simply called @Advice for this purpose.

4. What is @ControllerAdvice?

@ControllerAdvice allows us to define cross-cutting controller behavior in one place.

A common use is global exception handling.

Example:

@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception.class)
    public ResponseEntity<String> handle(Exception ex) {
        return ResponseEntity.internalServerError().body(ex.getMessage());
    }
}

For REST APIs, @RestControllerAdvice is commonly used.

5. What is @Aspect?

@Aspect is used with Spring AOP (Aspect-Oriented Programming) to define cross-cutting behavior.

Common use cases:
- Logging
- Auditing
- Performance monitoring
- Security-related cross-cutting logic

An aspect can intercept method execution using pointcuts and advice.

## Dependency Injection

6. What is Dependency Injection in Spring Boot?

Dependency Injection means Spring creates and supplies the dependencies required by a class instead of the class creating those dependencies itself.

Constructor injection is generally preferred.

Example:

@Service
public class OrderService {

    private final OrderRepository repository;

    public OrderService(OrderRepository repository) {
        this.repository = repository;
    }
}

7. What is the difference between @Component, @Service, @Repository and @Controller?

@Component:
General-purpose Spring-managed component.

@Service:
Normally used for service/business logic.

@Repository:
Normally used for persistence/data-access components.

@Controller:
Used for Spring MVC controllers.

@RestController:
Used commonly for REST controllers and combines @Controller with @ResponseBody.

## Configuration

8. What is application.properties/application.yml used for?

They are used to externalize application configuration such as:
- Server port
- Database configuration
- Logging
- Spring profiles
- Application-specific properties

9. What are Spring Profiles?

Profiles allow different configurations to be used for different environments, such as:
- dev
- test
- staging
- production

Example:
spring.profiles.active=dev

10. What is @Value?

@Value is used to inject a property value into a Spring bean.

Example:

@Value("${app.name}")
private String appName;

11. What is @ConfigurationProperties?

@ConfigurationProperties binds a group of external configuration properties to a Java object.

It is useful when an application has multiple related configuration properties.

## REST and Web

12. What is the difference between @Controller and @RestController?

@Controller is commonly used for MVC controllers and can return views.

@RestController is designed for REST APIs and includes @ResponseBody behavior by default.

13. How do you handle exceptions globally in Spring Boot?

Use @RestControllerAdvice with @ExceptionHandler.

This allows common exception handling logic to be centralized instead of repeating try/catch blocks in every controller.

14. What is @RequestMapping?

@RequestMapping maps HTTP requests to controller classes or methods.

More specific annotations include:
- @GetMapping
- @PostMapping
- @PutMapping
- @PatchMapping
- @DeleteMapping

## Interview Reminder

When answering Spring Boot questions, avoid saying:
"Spring Boot automatically configures everything."

Better answer:
"Spring Boot provides conditional auto-configuration based on the classpath, existing beans, configuration properties and other conditions."
